##Interactive Guessing Game

A web-based logic game developed to demonstrate foundational web development skills, specifically focusing on dynamic DOM manipulation and state management.

##Project Overview
This project is an interactive number-guessing game where users attempt to guess a randomly generated number between -20 and 20. 
The application provides dynamic, context-aware clues to guide the user toward the correct answer.

##Features
- Randomized Game Logic: Generates a new target number for every session using JavaScript’s Math libraries.
- Dynamic Clue Engine: Provides real-time feedback and mathematical hints based on the current number’s properties (even/odd, divisibility, sign).
- Responsive UI: Styled using CSS to provide a clean, user-friendly interface.

##Tech Stack
- HTML5: Used to define the semantic structure of the game interface.
- Vanilla JavaScript: Utilized for core game logic, event handling, and real-time DOM updates.

##Live Demo

##How to Play
- Click the "New Game" button to initialize the game and generate a secret number.
- Observe the clues provided in the main window.
- lick "Guess Number" to input your guess.
- Receive immediate feedback on whether your guess was correct.
